# CodeMemory

CodeMemory is an AI-powered code review agent that learns from previous code reviews.

The project uses Hindsight as its memory system so the agent can remember previous feedback, coding patterns, and preferences and use that information in future code reviews.

## Goal

Build a code review assistant that becomes more useful over time by learning from past interactions.

## Technologies

- Hindsight
- AI / LLM
- Python
- Git
- GitHub
